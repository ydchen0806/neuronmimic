# 给吴老师：精细树几何提供了可复现的连接预测信息

本轮从完整已知ap1细类型入手（左148、右133），把胞体位置/距离、单细胞树描述量与区域神经树接近性分开比较。在同一只果蝇中，区域树模型在左右各五个空间留出块、两个跨侧预测方向都优于描述量模型。这回应了“不能只用胞体坐标，要进一步建模树形态和实际空间关系”的要求。

| 评价 | 左侧训练：描述量→区域树 log loss | 右侧训练：描述量→区域树 log loss |
| --- | --- | --- |
| 无序神经元对留出 | 0.57461→0.52815 | 0.54515→0.51274 |
| 胞体空间块留出 | 0.60146→0.56618 | 0.59826→0.57348 |
| 预测另一脑侧 | 0.56142→0.54163 | 0.60188→0.55497 |

**明确结论：在当前ap1类型内，精细树的相互空间关系比胞体位置和单细胞树统计量提供更多连接预测信息。** 本轮没有使用图度数、候选标签或图嵌入作为预测特征，避免用这些信息替代几何解释。区域树特征同时加入距离核、区域长度与缺失标记，尚未分离各项机制贡献。

空间留出没有共享细胞，但没有边界缓冲；最小跨集合胞体距离2.474μm，不能视为完全空间独立。两侧属于同一动物，跨侧迁移不是跨个体复现。区间为固定模型的顶点重采样，未覆盖重拟合与动物差异。所有实验为回顾性结构预测，不是动态仿真或功能测量。

18细胞对象保持探索性：16个历史CM030成员加2个CM019成员。随机删边稳定不能弥补低计数边敏感性；离散标签的嵌套增益区间跨零，1000个匹配对照均未通过平衡门槛，PN/MBON匹配显著性为NA。不能把它命名为已验证新功能单元。

数据基础已得到进一步核实：MaleCNS的31,355个注释缺失端点全部存在于同版本递质表；BANC应使用root_888/banc_888_id而非当前root别名。独立个体的细类型映射、区域注册和几何评价仍未完成。

实际运行：281个KC、39,312个有向非自连对；模型种子20261101–03，108个保留模型，各4个调参设置。原始模型阶段23.35秒；右侧几何计算约201.89秒，CPU运行。公开版28项测试通过；独立进程重算475,722行预测最大差异为0，108模型权重一致。stable8及18细胞成员文件哈希未改变。

下一步应把已经固定的几何模型迁移到独立连接组，先过区域/类型映射QC；同时在训练/验证范围内分解区域长度和接近性贡献，冻结后再检验。只有候选在几何之外的残余信息通过独立路由与实验检验，才进入功能单元命名。当前结果加强了形态—连接组织的计算证据，尚未完成Nature主刊所需的独立功能和因果证据链。
